# 印样工作台

开发分支 `design/impeccable-lumina`，基于已发布的 Lumina `144a8c1`，按用户确认的“印样工作台”方向重新设计。源码发布记录见提交历史与 Actions；本轮没有部署或新增供应商。

矿物灰作为工作背景，深梅色组织文字和主要操作，赭黄标识选中的参数。自托管 Hanken Grotesk 与系统中文字体共用同一排版层级；薄分隔线和明确留白取代装饰性大卡片。首页用可选提示词与原创几何印样说明创作入口，明确标记为非 AI 生成。

工作台把配方和大画布并排，额度位于上方。手机采用独立导航轨道与结果跳转。Ctrl/⌘+Enter 通过原生表单校验提交；提交后聚焦真实结果区，手机滚动到结果。图片可放大或适应画布，下载、复用与删除仍走原来的私有接口。详情保留请求 ID、参数和可恢复状态。排队和结果未知时不提供复用入口，避免把旧请求的恢复误当作一次新生成。

作品库保留状态筛选、仅搜索已加载提示词、刷新与加载更多。账户页直接读取相同的工作室额度。登录/注册切换保留经过安全过滤的返回路径，选择的预设可继续进入工作台。中英、主题、加载/空/错/禁用状态、原生键盘焦点和减弱动画偏好共用设计规则。

设计令牌与扩展原则见 [DESIGN.md](../DESIGN.md)，实际检查见 [verification.md](verification.md)。组件主要位于 `src/components/lumina/`；共享样式、认证、账户与页面壳负责统一系统。新增 `allowance.tsx`，没有修改生成服务、数据库迁移、支付账本或私有文件授权。

预览：`E2E_PORT=4473 npm run demo:local`。仅使用脚本显示的虚构账号与持续标记的本地 fixture；生产代码不含 fixture 供应商分支。验证没有证明真实 AI、支付、邮件或线上性能，亦没有增加后台任务队列。
