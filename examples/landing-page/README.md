# Optional illustrative landing layouts

The default application uses a concise hero, features, configured pricing, FAQs and optional newsletter. These original layout examples preserve the larger illustrated landing toolkit without publishing fictional customers or metrics by default.

`blocks/` contains an illustrated hero, layout variants, platform/logo presentation, stat layout, call to action and explicitly illustrative testimonials. Imports use the application's `@/` alias. Import the desired component into `src/components/blocks/homepage.tsx` and supply product-specific, authorized copy before launch. Existing shared CSS tokens/layout styles remain available.

The examples are not routes, do not configure providers and are not included in the default production component tree. Replace any sample statistics and testimonial text with verified information. They are not a source of production revenue or usage data.
